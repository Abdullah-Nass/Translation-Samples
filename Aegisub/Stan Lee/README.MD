# Stan Lee Speech – Arabic Burned-in Subtitles

This project contains my Arabic subtitle translation of a Stan Lee speech video. The subtitles were created and timed using **Aegisub**, then burned into the video using **FFmpeg**.

## Video

Original video:  
https://www.youtube.com/watch?v=5aR-5cNABAI

## About the Project

The speech was translated from English into Arabic with attention to meaning, timing, readability, and natural subtitle style. The final output includes a video file with the Arabic subtitles permanently burned in.

## Tools Used

- **Aegisub** – subtitle translation, timing, editing, and styling
- **FFmpeg** – burning the subtitles into the video

## Files

- `.ass` subtitle file: Arabic translated and timed subtitles
- Burned-in video file: final video with Arabic subtitles embedded permanently
